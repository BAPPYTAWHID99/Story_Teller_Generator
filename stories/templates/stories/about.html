About

Story Teller Generator

A Django-based procedural story-generation application that transforms user-defined creative parameters into a complete narrative.

The project is designed to help users create imaginative stories by combining genre, character, location, theme, mood, and length into a cohesive written experience. It focuses on a clean architecture where forms validate user choices, a generation engine composes the narrative, and a public API provides optional inspirational enrichment without depending on it for the core story.

Features

  • Responsive single-page storytelling experience
  • Structured story generation with genre-driven worldbuilding
  • Database persistence for all generated stories
  • Story history, viewing, deletion, and regeneration
  • API-powered inspirational quote fallback
  • Modern interface and accessible forms

Technology Stack

Python, Django, SQLite, HTML5, CSS3, JavaScript, Bootstrap-inspired custom UI, and the Python requests library.

Story-generation methodology

Each story is assembled through a template generator that blends plot structure, narrative beats, character identity, setting, and mood. The design keeps business logic separate from view handling and allows a future AI-backed generator to slot into the same interface.

Database and API integration

Generated stories are saved into SQLite, and a public quote API is queried only as an optional inspiration layer. If the API is unavailable, the application continues without exposing technical errors to the user.

Future improvements

Future enhancements could include multilingual story generation, user accounts, downloadable stories, and a plugin architecture for AI-backed story generation.
